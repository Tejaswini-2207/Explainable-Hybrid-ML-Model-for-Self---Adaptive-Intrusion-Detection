# Explainable-Hybrid-ML-Model-for-Self---Adaptive-Intrusion-Detection
Intrusion Detection System is a cybersecurity project developed to detect suspicious activities and potential threats in a computer network. The system analyzes network traffic data and identifies whether an activity is normal or malicious. Data preprocessing techniques were used to clean and prepare the dataset for analysis.
## Intrusion Detection System

A machine learning-based security project designed to detect malicious network activities and classify potential cyberattacks.

### Features
- Data preprocessing and feature extraction
- Attack classification using machine learning
- Performance evaluation and visualization
- Network traffic analysis

### Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib
