
# Explainable Hybrid ML Model for Self-Adaptive Intrusion Detection

## Overview
This project uses Machine Learning to detect suspicious network activities and classify potential cyberattacks. The model analyzes network traffic data and helps improve network security through intelligent threat detection.

## Features
- Detects malicious network activities
- Classifies normal and attack traffic
- Data preprocessing and analysis
- Machine Learning-based prediction
- Performance evaluation and visualization

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Applications
- Network Security
- Cyber Threat Detection
- Intrusion Monitoring Systems
